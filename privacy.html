Privacy policy

Last updated: October 27, 2026

This page explains what Pippo, a Discord bot for games and quizzes, processes when you use it. Pippo is operated by its developer and runs inside Discord servers.

✳

In plain English
Pippo keeps the IDs and game progress needed for its features. It reads game answers while a round is active. It does not save those answer messages to its database.

Information Pippo processes

When commands or games run, Pippo may receive Discord user IDs, server IDs, display names, command names, and the messages or button selections needed to respond. Discord itself handles your account, messages, and interactions under its own policies.

Pippo stores these bot records in its PostgreSQL database:

  • Server IDs and a server's chosen command prefix.
  • User IDs and command names, with the time a command ran and the server ID when it ran in a server. This is used for bot analytics.
  • User IDs with Bollywood or plot-game scores and rounds played.
  • User IDs with virtual coin balances and selected character preferences, such as a show, cartoon character, dog breed, or cat breed.
  • User IDs and greeting preference settings.

When Pippo joins a server, it also sends the server's name and ID to its developer through Discord so the developer can see that Pippo was added.

Messages and game answers

Pippo reads ordinary channel messages when a game is waiting for a guess or a word, and reads messages used to invoke prefix commands. The bot processes those messages to run the requested feature. The message text is not intentionally written to Pippo's database; game state is kept in memory while the round runs.

Discord may retain or process messages and interactions independently of Pippo. For how Discord handles that information, see Discord's Privacy Policy.

AI judging in Clash

If the operator has enabled AI judging, Pippo sends the two players' Discord display names and submitted fictional creations to OpenRouter to judge that Clash round. Requests ask OpenRouter to route only to providers that deny data collection and support zero data retention, and require structured-output support. If no qualifying route is available, or the integration is unavailable, Pippo chooses a winner at random. Regular movie guesses and other channel messages are not sent to OpenRouter by this feature.

OpenRouter says it does not train on inputs or outputs, but the selected model provider processes the request and its own data practices may differ or change. Please do not submit sensitive or confidential information in Clash. See OpenRouter's Privacy Policy and provider routing documentation.

Why information is used

Pippo uses the information above to respond to commands, run games, keep scores and coin balances, remember selected characters and server preferences, and understand which commands are used. The website does not include advertising or analytics trackers.

The website is hosted on GitHub Pages. GitHub may process technical information about requests to serve and secure the pages; see GitHub's Privacy Statement.

Storage and retention

Bot records are stored in a PostgreSQL database used to operate Pippo. The bot does not currently apply an automatic deletion schedule to these records. Some game state exists only in memory for the duration of a round. This website is a static page and does not ask you to create an account or submit personal information.

Your choices and deletion requests

You can choose not to use Pippo or its games. To ask the developer to remove bot records linked to your Discord user ID, contact the team in the Pippo support server and describe your request. A server administrator can change or remove a server's prefix through the bot's settings command.

Changes to this policy

This policy may be updated as Pippo's features or data practices change. The date at the top shows when it was last revised. Please review the current version when you use Pippo.

Questions?

Contact Pippo's developer through the support server.
